# 4G 遥控车微信小程序

小程序底部有「控制」和「设置」两个 Tab。控制页通过 WebView 打开自建服务器上的 WebRTC 遥控台，普通和全屏界面都显示前进／后退与转向摇杆。前进／后退目前为界面预览。

## 导入和真机预览

1. 在微信开发者工具选择「导入项目」，目录选本文件所在的 `miniprogram/`，使用有 `web-view` 业务域名配置权限的小程序 AppID。工程中的 `touristappid` 供本地打开项目使用。
2. 在微信公众平台把实际使用的 HTTPS 域名加入该 AppID 的**业务域名**并完成验证。每个自建域名都要先在后台获准，或由部署者使用自己的 AppID 完成配置。
3. 通过开发者工具生成预览二维码，用手机微信扫码。在「设置」粘贴完整私有遥控链接并保存，或填写服务器 HTTPS 域名和 64 位观看密钥。保存后自动进入「控制」，后续打开小程序会复用该配置。

观看密钥保存在当前设备的小程序本地存储中，在打开控制页时放进 URL 的 `#` 片段。发布包内没有预置访问密钥。给其他人部署时，沿用服务端的 `/p4-intercom/rtc/` 路径，使用本版本的 H5 页面和资源以支持浅色主题，并生成独立的观看密钥。

看到 `web-view load failed due to not in domain list` 时，检查当前 AppID 的「开发管理 → 开发设置 → 业务域名」。填写 HTTPS 站点的域名，省略 `/p4-intercom/rtc/` 路径；微信要求校验时，保留下载的校验文件原名和内容，并通过域名根路径公开提供该文件。验证并保存后，重新编译小程序。

## 真机验收

分别在 iPhone 和 Android 微信中，用走 4G 的小车验证实时画面、收听和手机麦克风回传。打开全屏并转动手机，确认摇杆仍可操作。在车轮离地的情况下验证松手、返回连接页和切后台时的舵机回中。进入遥控台前先退出其他已连接的 H5 遥控会话。

全屏时会优先请求系统横屏。微信 WebView 无法锁定方向时，遥控界面会在当前视口内旋转，摇杆按横屏方向响应。切换「控制」和「设置」保留当前 WebView，保存不同的服务器地址或访问密钥时才会主动切换会话。

打开画面上的「翻转」可分别切换水平和垂直翻转。设置保存在本机，普通和全屏视图共用，切换时保留正在播放的连接。

点击画面左上方的清晰度按钮可选标清 640×360 或高清 1280×720。调整后视频会短暂重新连接，选择保存在本机。高清开始播放后，菜单会显示实际分辨率。
