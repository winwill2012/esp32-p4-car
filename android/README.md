# Android 小车遥控

适用于 Android 8.0 及以上版本。安装 APK 后，在「设置」填写服务器公网 IPv4，或直接粘贴部署生成的 `setup-output/android-link.txt`。选择「保存并连接」进入控制台。首次开启麦克风时允许 Android 的录音权限。

控制台使用原生 WebRTC 渲染视频和收发音频。全屏时切换为横屏，上下或左右翻转和清晰度在「画面」菜单调节。打开「设置」会释放摇杆并关闭麦克风，返回时继续使用当前连接。保存不同的服务器或直连选项会建立新连接。

非全屏控制页右上方的「切换小车」显示同一服务器登记的小车和在线状态。选中另一辆车时，App 会先结束旧车的通讯，再连接新车，并记住当前选择。

画面上方的「大灯」用于开关前灯。车端支持灯光联动时，后拉左摇杆会点亮倒车灯，右摇杆向左或向右会让对应转向灯闪烁。松手后联动灯熄灭，结束通讯时四路灯全部熄灭。

服务端部署见 [公网 IP 部署说明](../server/README.md)。IP 证书须由 Android 系统信任，并与用户填写的公网 IP 匹配。

## 构建

在 Android Studio 打开本目录，使用 JDK 17 和 Android SDK 35。命令行可使用项目自带的 Gradle Wrapper。

```sh
./gradlew :app:assembleDebug
```

调试 APK 位于 `app/build/outputs/apk/debug/`。用于公开分发的版本请用自己的发布密钥签名，后续更新使用同一密钥。
